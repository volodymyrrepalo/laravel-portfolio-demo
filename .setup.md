# Lara Repalo portfolio setup

Laravel portfolio application, developed locally with Lando, MySQL, Livewire,
and Laravel Reverb.

## Prerequisites

Install Docker Desktop (or Docker Engine) and [Lando](https://docs.lando.dev/).
This repository intentionally begins with the Lando definition only; Laravel is
installed through Lando so its PHP and Composer versions match local development.

## First-time setup

From this directory, run:

```bash
lando start
lando composer create-project laravel/laravel /tmp/lararepalo-bootstrap --no-interaction
lando ssh -c 'cp -a /tmp/lararepalo-bootstrap/. /app/'
lando composer require livewire/livewire laravel/reverb
lando artisan install:broadcasting --reverb --no-interaction
cp .env.lando.example .env.lando
```

Laravel is created in the container's temporary directory and copied into the
project root, which preserves the Lando files already present. Copy the settings
in `.env.lando` into the generated `.env`, preserving the generated `APP_KEY`.
Then run:

```bash
lando artisan key:generate
lando artisan migrate
lando npm install
lando npm run build
```

Open `https://lararepalo.lndo.site:444`.

## Daily development

```bash
lando start
lando npm run dev
lando reverb
```

Run `lando reverb` in a separate terminal and leave it running while developing
real-time features. Its TLS WebSocket endpoint is
`wss://reverb.lararepalo.lndo.site:444`.

Useful commands:

```bash
lando artisan make:livewire Portfolio/ProjectList
lando artisan migrate
lando mysql
lando stop
```

## Services

| Service | Local connection |
| --- | --- |
| Laravel | `https://lararepalo.lndo.site:444` |
| MySQL | host `database`, port `3306`, database/user/password `laravel` |
| Reverb | `wss://reverb.lararepalo.lndo.site:444` (internal port `8080`) |

`lando info` displays the current service credentials and URLs. Use it as the
source of truth if the project name or Lando configuration changes.
